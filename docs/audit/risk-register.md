## Immediate Phase 1 gates

1. Decide and document auth, tenancy/RLS, service boundaries, contracts, job substrate, agent profile, flow graph, object storage, and single-VM topology in ADRs.
2. Make real telephony and WhatsApp impossible by default before importing provider code.
3. Establish one locked Node/pnpm and Python/uv workspace without moving source behavior yet.
4. Create one PostgreSQL/Alembic skeleton and architecture tests that reject prohibited runtimes.
5. Resolve Or-on ownership and high-risk model/SDK license questions before code/model distribution.
